These are drafts of reports to two of the pinned oracle projects, written for the project owner to file in each project's own issue tracker (register H27: defects as bug reports, disagreements with a documented rule as questions citing the source; drafted by the agent, filed by the owner). Nothing here has been filed yet. Each draft stands without this repository.

**Bug reports** (ruling R7 in `docs/rules/README.md`). Each gives a minimal reproduction, the expected and the actual output, the root cause at the pinned commit, and the rule cited from public sources. The evidence behind them is in `docs/checkpoints/checkpoint-1-check-clusters.md` ("Mate traces" and "Count trace"). Every reproduction was re-run against the pinned code on 2026-10-01: 5d-chess-js was loaded at its pinned commit, with its suggested fix also checked by applying it in memory, and ftxi was run as its stock `5dtools`, built from its pinned commit.
