# 5D Chess Engine — Decision Register

Companion to `5d-chess-transformer-design.md` (the spec) and
`scalable-transformers-architecture.md` (the general pattern). The spec holds the
reasoning; this register holds the **state** of every decision, so that "what did we
decide, and how firmly" has one answer. Section pointers (§) refer to the spec.

**Status vocabulary**

| Status | Meaning |
|---|---|
| Committed | Settled; part of the v1 build |
| Provisional | Adopted for v1, pending a named measurement |
| Prototype | Build behind a flag; adopt only if the ablation says so |
| Held open | A candidate with a reason to exist, not scheduled |
| Deferred | Decided to decide later, with a stated condition |
| Refused | See §14 for the principle each violates |
| Reversed | A prior decision changed — history in Part J |
| Retired | Planned or built once; its role ended — kept for the record |
| Superseded | Replaced by the named row; not built |
| Killed, provisionally | Judged by its pre-registered rule and not built; re-checked by the named measurement |
| Prepared | Built behind a flag and smoke-tested; not adopted |
| Measured | The figure is recorded and its verdict is in the row |
| Adopted under / Not adopted in | Shipped as measured, per board-count range |
| Undecided | Committed-class with every arm built; decided by the named ablation before the freeze |
| Open knob | A tunable with no committed default |
| Contingency | Decided for v1 — not built — and reopened only if every named trigger holds |

**Class**: **C** = committed-class (irreversible once serious self-play training starts —
must be decided before it); **R** = retrofittable; — = process or principle. Class C rows
are decided at the freeze (spec §15.7, M25): a row whose experiment has not run by then is
decided for its v1 default, and says so.

**As-built forms** — bins, widths, initialisations, placeholder constants — are pinned in
spec §16, keyed by the row IDs used here (M27). Rows that carry a decision of the
2026-11-15 review say so; the full list of those decisions, which await the owner's
confirmation, is in docs/BUILD_LOG.md.
